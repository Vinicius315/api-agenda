# Nível escolhido: Projeto B — API de Agenda

API REST de domínio único para agendamento e controle de conflitos de horários, desenvolvida com Node.js, Express e PostgreSQL.

## Como executar (em construção)
1. Copie `.env.example` para `.env` e ajuste as variáveis locais.
2. Suba o banco com `docker compose up -d`.
3. Instale as dependências com `npm install` e inicie com `npm run dev`.
